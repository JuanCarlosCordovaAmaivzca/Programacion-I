# Programación 1

Programas y ejercicios hechos en la materia de Programación 1, en Python.
Cada programa está en su propia carpeta.

## Programas

| Carpeta | Descripción |
|---|---|
| `blackjack` | Juego de Blackjack con apuestas. |
| `butacas_cine` | Reserva de butacas en una sala de cine. |
| `cifrado_cesar` | Cifra un texto con el cifrado César. |
| `contraseña_segura` | Revisa si una contraseña es segura. |
| `determinar_numero_dias_mes_1900_2026` | Dice qué día de la semana es una fecha. |
| `figuras_asteriscos` | Dibuja una casa y triángulos con asteriscos. |
| `juego_de_luces` | Apaga todas las luces cambiando una y sus vecinas. |
| `matrices` | Reloj de arena con asteriscos y suma de vecinos de una matriz. |
| `memorama_en_1d` | Juego de memoria para encontrar parejas de números. |

## Requisitos

- Python 3
- Librerías: `numpy`, `emoji` e `IPython`

```
pip install numpy emoji ipython
```

## Cómo ejecutar

Entra a la carpeta del programa y ejecútalo:

```
cd blackjack
python BLACKJACK.py
```
